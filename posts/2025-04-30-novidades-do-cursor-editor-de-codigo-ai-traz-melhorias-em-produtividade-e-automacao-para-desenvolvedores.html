Novidades do Cursor: Editor de Código AI traz melhorias em produtividade e automação para desenvolvedores

Felipe Vieira 30 de abril de 2025 🇧🇷 Português 3 min read

O Cursor, um editor de código de ponta movido por inteligência artificial, continua a redefinir a forma como os desenvolvedores interagem com o código. Com a versão mais recente, lançada em 15 de abril de 2025, o Cursor traz uma enxurrada de atualizações pensadas para turbinar a produtividade e a automação nos fluxos de trabalho dos desenvolvedores. Acompanhe as novidades que tornaram essa atualização um divisor de águas.

1. Geração de Regras Automatizada

A mais recente capacidade de geração de regras permite que os usuários capturem e reutilizem o contexto pré-existente de maneira mais eficiente. Com o comando /Generate Cursor Rules, é possível gerar regras diretamente a partir de conversas, promovendo a automação de tarefas repetitivas com facilidade.

2. Histórico mais Acessível

A integração do histórico de chat ao menu de comando é uma atualização importante. Agora, com um simples clique em “Mostrar Histórico” ou com o comando Show Chat History, os desenvolvedores podem acessar e revisar interações passadas sem esforço adicional.

3. Facilidade em Revisões

Verificar as alterações no código nunca foi tão simples. A nova funcionalidade de visualização de diferenças integrada ao final de cada conversa permite que os desenvolvedores rapidamente avaliem as mudanças feitas pelo AI, ofertando um botão intuitivo de “Review changes”.

4. Suporte a Imagens em MCP

O suporte a imagens nos servidores MCP é uma adição significativa, permitindo que os usuários incluam imagens como parte do contexto. Isso é particularmente útil em perguntas necessitando de contexto visual, como capturas de tela e diagramas. Saiba mais sobre MCP.

5. Controle Aprimorado do Terminal do Agente

Com maior controle sobre terminais iniciados pelo agente, os desenvolvedores podem editar ou pular comandos antes de executá-los. Isso aprimora as interações com o terminal, e a função “Pop-out” foi renomeada para “Mover para o fundo” para maior clareza.

6. Arquivos de Ignorar Globais

Agora você pode definir padrões de ignorar que se aplicam a todos os projetos, evitando que arquivos não essenciais ou sensíveis sejam incluídos automaticamente nos prompts, melhorando significativamente a eficiência dos fluxos de trabalho.

7. Novos Modelos

A mais recente versão do Cursor introduz novos modelos de AI, incluindo o Gemini 2.5 Pro, Grok 3, e GPT-4.1, disponíveis nas configurações de modelo. Esses novos modelos garantem melhorias robustas na capacidade de processamento e geração de código.

8. Melhorias e Correções

O Cursor não apenas trouxe novas funcionalidades, mas também diversas correções de bugs e melhorias de estabilidade, como a resolução de problemas com o editor de regras e a exibição de delimitadores em terminais.

Exemplo de Código com Cursor AI

Com o Cursor AI, gerar código em diferentes linguagens é uma tarefa simples. Por exemplo, para criar uma classe em Python, basta usar um comando natural no painel de chat do Cursor.


# Gerando uma classe simples em Python com Cursor
class Vehicle:
    def __init__(self, name, max_speed, mileage):
        self.name = name
        self.max_speed = max_speed
        self.mileage = mileage

    def display_vehicle(self):
        print(f"Name: {self.name}, Speed: {self.max_speed}kmph, Mileage: {self.mileage}kmpl")

Configurando o Cursor para React e Next.js

Para maximizar o uso do Cursor com React e Next.js, uma configuração correta é crucial. Usar um guia dedicado para esses frameworks pode aumentar sua produtividade e eficiência na escrita de código. Aprenda mais sobre como configurar idealmente.

Custo e Planos do Cursor

O Cursor oferece uma versão gratuita que atende a maioria das necessidades dos desenvolvedores, complementada por um plano Pro a $20/mês, que inclui funcionalidades avançadas para profissionais que requerem recursos adicionais.

Conclusão

Com essas novas funcionalidades e melhorias, o Cursor reafirma sua posição como um dos editores de código centrados em AI mais poderosos do mercado. Oferecendo produtividade aprimorada, automação inteligente e integração focada nas necessidades dos desenvolvedores, o Cursor é uma ferramenta essencial para quem busca eficiência no desenvolvimento de software.
