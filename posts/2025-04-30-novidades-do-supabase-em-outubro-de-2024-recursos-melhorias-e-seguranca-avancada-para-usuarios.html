Novidades do Supabase em Outubro de 2024: Recursos, Melhorias e Segurança Avançada para Usuários

Felipe Vieira 30 de abril de 2025 🇧🇷 Português 2 min read

Supabase continua a surpreender com novas atualizações, avanços inovadores e aprimoramentos que facilitam o desenvolvimento e a gestão de projetos. Com uma série de melhorias voltadas para segurança, autenticação e experiência do usuário, este artigo destaca as últimas novidades que podem transformar a maneira como você utiliza a plataforma.

Papéis de Projeto com Escopo Limitado

Agora, os papéis dentro da Supabase podem ter um escopo restrito a projetos específicos, oferecendo um controle mais refinado sobre as permissões de usuário. Por exemplo, apenas integrantes selecionados poderão acessar determinados dados de projetos. Aprenda mais sobre configurações de autenticação e autorização.

Interface do Painel Renovada para Organizações

A interface do painel de controle foi completamente reformulada para melhorar a navegação entre membros da equipe e organizações. Isso facilita a gestão de vários projetos simultaneamente. Confira um artigo completo sobre o novo design do painel.

Cobrança Detalhada e Explicativa

O detalhamento de cobranças foi aprimorado, agora com links de documentação que explicam cada item. Isso significa melhor compreensão dos custos, ajudando na gestão financeira eficiente. Veja mais detalhes sobre planos de preços e seus recursos.

Logs de Atualização do Banco de Dados

Os logs de atualização agora são acessíveis dentro do Supabase, permitindo uma inspeção minuciosa das operações ocorridas no banco de dados. Isso é crucial para solucionar problemas rapidamente.

Recursos de Visualização Local

No ambiente auto-hospedado do Supabase Studio, agora você pode pré-visualizar recursos localmente, uma adição altamente útil para desenvolvimento e depuração. Saiba mais sobre desenvolvimento local no Supabase.

Novos Anúncios de Produtos

Supabase expandiu suas funcionalidades, incluindo o suporte a Deno 2.1, melhorando assim a eficiência do desenvolvimento. Veja os detalhes na nossa postagem sobre suporte ao Deno.

Integração com Firebase Auth

A integração com o Firebase Auth foi oficialmente lançada, incentivando uma autenticação externa mais robusta. Com isso, os usuários podem aproveitar uma interface mais integrada e segura.

Alertas de Segurança Aprimorados

Os alertas de segurança receberam uma atualização significante para detectar e reagir rapidamente a problemas de performance e segurança. Consulte as documentações de segurança no Supabase para mais informações.

Editor de SQL Avançado

Agora, o Editor de SQL conta com finalizações de código utilizando um Assistente, que sugere otimizações nas consultas SQL, permitindo uma escritura mais eficaz e simplificada.


  -- Criar uma função simples no Editor de SQL
  CREATE OR REPLACE FUNCTION hello_world()
  RETURNS TEXT AS $$
  SELECT 'hello world';
  $$ LANGUAGE SQL;

Gestão Eficiente de Envios de Email

Com mudanças implementadas no envio de emails, a gestão e o controle do uso do serviço de emails estão mais estratégicos, visando eficiência e responsabilidade no envio de mensagens. Saiba mais sobre as políticas de envio de mensagens.

Supabase: Inovação e Segurança

Com atualizações constantes e atendendo às demandas dos desenvolvedores, Supabase se posiciona como uma solução robusta. Conheça todas as melhorias e fique por dentro das novas funcionalidades preparadas para os próximos meses.

API Keys e Funcionalidades Futura

A introdução de API Keys avançadas e novos endpoints para Edge Functions prometem trazer mais segurança e eficiência. Os desenvolvedores são incentivados a explorar essas novidades e prepararem suas transições com tempo adequado.

Saiba mais sobre a evolução contínua e as atualizações futuras do Supabase diretamente no blog oficial do Supabase.
