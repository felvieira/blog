ChatGPT agora interage com aplicativos de desktop do Mac para otimizar o desenvolvimento de software

Felipe Vieira 3 de dezembro de 2024 🇧🇷 Português 2 min read

A OpenAI está inovando ao permitir que o ChatGPT interaja com aplicativos desktop do macOS, revolucionando a forma como desenvolvedores front-end e back-end trabalham com código. Essa nova funcionalidade é intitulada “Work with Apps”. Com suporte para diversos aplicativos de codificação como Visual Studio Code (VS Code), Xcode, TextEdit, Terminal e iTerm2, essa novidade promete eliminar a necessidade de copiar e colar códigos para diálogo. Descubra como essa integração pode transformar o seu fluxo de trabalho.

Como Funciona

Para usufruir dessa funcionalidade, os desenvolvedores devem habilitar a opção dentro do aplicativo ChatGPT. Uma vez ativada, a aplicação automaticamente envia as seções relevantes do código para o ChatGPT, garantindo um contexto aprimorado a cada interação. Assim, o ChatGPT responde de maneira mais rápida e contextualizada, atendendo de forma eficiente às perguntas dos desenvolvedores. Saiba mais sobre como essa integração pode simplificar seu processo de codificação em openai.com/research.

Aplicativos Compatíveis

  • Visual Studio Code (VS Code): Requer uma extensão especial para consultar conteúdo. Veja mais em Visual Studio Code Docs.
  • Xcode: Um popular ambiente de desenvolvimento integrado (IDE) para macOS.
  • TextEdit: Editor de texto básico que vem com macOS.
  • Terminal: Interface de linha de comando para execução de comandos.
  • iTerm2: Emulador de terminal alternativo para macOS. Explore mais em iTerm2.

Exemplo de Fluxo de Trabalho

  1. Habilitar a Funcionalidade: Abra o aplicativo ChatGPT e ative a opção “Work with Apps”.
  2. Selecionar o App: Escolha o aplicativo de codificação em que você está trabalhando, como o Xcode.
  3. Perguntar ao ChatGPT: Solicite ao ChatGPT uma tarefa, como adicionar o planeta que falta em um modelo de sistema solar.
  4. Resposta do ChatGPT: O ChatGPT analisará o código e fornecerá uma resposta, que deve ser então colada de volta no ambiente de trabalho.

Planos Futuros

A OpenAI está priorizando aplicativos de codificação, mas planeja expandir esta funcionalidade para outros aplicativos baseados em texto utilizados em tarefas de escrita. A empresa está explorando maneiras de tornar a aplicação de sugestões mais direta, trabalhando para integrar o ChatGPT com mais aplicativos, incluindo talvez ferramentas de produtividade como o Microsoft Word. Acompanhe essas atualizações em The Verge.

Requisitos do Sistema

O aplicativo desktop ChatGPT para macOS está disponível para dispositivos que executam macOS Monterey (12.0) ou versões posteriores, incluindo o macOS Ventura (13.0). Para um desempenho ideal, um Mac com chip Apple M1/M2 ou processador Intel, além de 8GB de RAM e 500MB de espaço de armazenamento disponível, é necessário. Encontre mais detalhes sobre requisitos no suporte Apple.

Disponibilidade

A funcionalidade “Work with Apps” está atualmente disponível para usuários Plus e Teams, e será oferecida a usuários Enterprise e Education nas próximas semanas. Esta integração visa tornar os fluxos de trabalho dos desenvolvedores mais eficientes, providenciando assistência de IA em tempo real diretamente nos seus ambientes de codificação. Saiba mais sobre essas ofertas em openai.com/pricing.

Com essas inovações, o ChatGPT está se posicionando como uma ferramenta essencial para desenvolvedores, promovendo maior produtividade e precisão no desenvolvimento de software. Fique ligado para mais atualizações sobre essa tecnologia empolgante!
